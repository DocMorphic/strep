# Bounded wrist correction and timed export

The preceding native full-body fit changed one wrist by 68 degrees while still leaving approach collisions. This experiment fits the desired wrist transform by distributing edits over the left shoulder, arm, forearm and hand. It preserves the root, torso, legs, opposite arm and all unselected local rotations. It is a development comparison on the same five body-guided seeds, not held-out release evidence.

`motion_edit_bounds.py` requires an explicit rotation and correction-speed budget for every joint, plus native root-axis displacement and correction-speed budgets. It measures shortest local rotation differences on SO(3), uses actual timestamps, rejects malformed matrices and raises a structured error on a violation. It never silently clamps a result. Correction speed means the rate of the edit relative to the source; it is not the character's original angular velocity. These are authoring budgets, not anatomical limits or realism certification.

`bounded_pose_ik.py` fits rigid-joint targets using forward kinematics, including hierarchies whose storage order differs from parent order. The experiment's total local-edit caps are shoulder 15°, arm 25°, forearm 35° and hand 30°, following the existing paired-arm experiment. The solver uses conservative component boxes inside those total-angle limits. This guarantees the caps but can exclude valid rotations within the full spherical budget. An unmatched target is therefore a failed local solve under this implementation, not proof that the target is impossible under every allowed pose.

All ten actors were tested. Nine match the desired event wrist position within 0.5 mm and orientation within 0.5°. Seed 2089 actor A remains 18.115° away in orientation, despite a 0.388 mm position residual. That failure is retained and is not relabeled because other actors pass. The successful solves distribute small edits across the arm; the fixed body pose remains unchanged.

`export_bounded_wrist_motion.py` applies each actor's bounded correction with a smooth envelope from frames 60 to 90, peaking at 75. It retains all ten results, including the failed target. The separate existing hand-posture layer can then apply the authored fingers, with a 60° total finger-edit cap. Every joint's correction-speed limit is 150°/s (5° per frame at 30 fps), and root edits are zero. Raw clips remain separate from the bounded body and body-plus-finger variants.

The first export attempt failed actual engine verification because NumPy advanced indexing transposed the position array's frame and joint axes. `joint_channels` now selects the joint axis explicitly; a regression test covers a reordered joint subset and distinct frame values. The failed run remains under `reports/bounded-wrist-motion-v1`. `repair_bounded_wrist_export.py` creates a separate repair, changes only the affected position-array axes, and checks every saved position/rotation against the unchanged actual GLBs. No solver rerun or changed animation is hidden in this repair.

The repaired population is `reports/bounded-wrist-motion-v1-repair-01`: thirty actor clips, including ten raw controls, passed 4,500 actual Godot actor-frame checks. Independent finger-preservation verification passes for every actor. `verify_bounded_wrist_motion.py` decodes the actual original and corrected GLBs at all 299 integer and half-frame samples across the clip. All twenty corrected candidates satisfy their sampled edit budgets and preserve motion outside the declared interval. These sampled results are not a continuous-time guarantee.

The complete surface audit finished under `reports/bounded-wrist-motion-audit-v1`: all 15 scenes, 180 samples per scene and 4,500 engine actor-frames. The source-bound summary is `reports/bounded-wrist-motion-summary-v1`. Every scene fails the whole-motion collision and floor screens. The five arm-plus-finger variants have peak depths of 23.09, 23.49, 21.30, 20.67 and 20.69 mm, at frames 67, 81, 73, 72 and 56. Root and feet were preserved, so this operation cannot repair their existing floor errors. The native full-body population's separate audit also completed with whole-motion failures. Neither import success nor budget compliance closes an animation-quality gate.

`reports/bounded-wrist-motion-review-v1/viewer.html` shows all fifteen variants with actual metrics and a Worst collision button. Browser checks confirmed retained clocks across version changes, a frame56 failure outside the old edit interval, half-frame81.5 navigation, the unresolved actor-A wrist target warning, and visible grey SOMA geometry. Browser console warnings/errors were empty. This review shows the earlier bounded v1 exports; the newer wider-path trial is separate.

Six focused tests pass across the budget, pose-solver and export-axis test files. Next work must address the conservative solver search space and full-motion scene constraints while retaining edit limits. Independent animator review, cleanup-time evidence and the broader action/rig release matrix remain open.
