# Local independent animation review

The new local review workflow prepares neutral clip IDs, collects human-entered ratings and actual cleanup records, and validates downloaded responses without inventing missing evidence. It does not assign release approval.

`scripts/review_session.py build` accepts a completed action job, a new output directory, a condition-key path outside that directory, and a randomization seed. It checks original GLB hashes, shuffles clips, removes extras, renames animation/scene labels, and copies motion into neutral filenames. Source files remain untouched. The separate organizer key maps neutral IDs to source IDs/seeds/hashes; keep it away from reviewers. This hides condition labels, not access to the whole machine. The current viewer uses the local workspace's Three.js runtime; it is not yet a standalone portable/offline installer.

Current packet: `reports/pose-response-human-review-v1`,36clips from the frozen cross-action study. Open `viewer.html` through the local8767server. Reviewers see the requested action, grey character and playback controls, but not generator labels, seeds, condition or measured quality diagnostics. They watch normal speed first and score action/intended limb, weight/balance, coordination/timing, contacts/collisions, and starts/ends from1to5. N/A needs a reason and is forbidden for action correctness. Major-defect and confidence fields are required.

A reviewer code and independent-human attestation are required before saving/export. Browser drafts are separated from saved reviews; changing a draft never silently upgrades an earlier score. After saving, reviewer code is fixed to prevent relabeling earlier reviews. Use a separate browser profile for each independent reviewer. Local JSON export contains only saved entries, packet/hash binding and reviewer identity. Missing clips remain missing. The page sends no ratings to a server.

Cleanup records must describe real editing of the downloaded clip. Enter active seconds excluding breaks/playback, actual operations, and completed/time-limited/abandoned status. Unperformed cleanup keeps times null; time-limited trials must identify a reached positive limit. Abandoned and censored attempts remain in the data. Time and independence are attestations, not automatically established facts. Paired cleanup reductions and agreement analysis are still outstanding.

Import an exported response with `scripts/review_session.py import PACKET RESPONSE --output NEW_DIRECTORY`. The importer rejects wrong packet/hash, changed assets, duplicate/unknown clips, invalid ratings, unexplained N/A, false/missing attestation and fabricated time fields for unperformed work. It preserves the response and reports missing clips without approving quality. Import folders are never overwritten.
