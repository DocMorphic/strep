## Inspect a region at an animation time

After previewing the selected region, expand **Inspect this surface during its animation**, enter an explicit **character-local time in seconds**, and select **Inspect animation surface**. The selected source or partner actor determines the animation index. The time is independent of the scene timeline and preview camera; positions use native character animation coordinates with no scene placement. Front, side and top views retain every selected triangle and vertex in the sampled pose. Gold arrows use the original triangle winding after skin deformation. A red diamond marks a degenerate triangle whose winding normal is unavailable; it stays in the geometry and receipt rather than being dropped or assigned a default normal. Exact sampled positions, corners, areas, centres and winding diagnostics are available below the views.

`/api/native-scene-material-region-pose` accepts the following separate inspection request:

```json
{
  "schema": "strep-studio-material-region-pose-v1",
  "id": "completed-region-preview-id",
  "preview_sha256": "exact-completed-region-preview-result-sha256",
  "animation_index": 0,
  "time_s": 0.5
}
```

The endpoint requires the exact completed source-bound region preview and the existing production lock. It fully checks that preview before and after reading the animated GLB with `NativeSupportSampler` and the existing normalized `RigAsset` skin implementation. Original STEP, LINEAR and CUBICSPLINE channels and exact-key behavior remain in the source. Times outside the selected animation duration reject without clamping, looping or conversion to a 30 Hz approximation. Static characters and unsupported animation channels reject. The native sampler's existing unsupported animated-scale, morph and extension limitations remain explicit. There is one full native skin sample per inspection; existing complete source mesh and selected-region budgets apply.

Each request retains a fresh separate `reports/material-region-pose-previews/<id>/` with `request.json`, `pose.json`, `result.json` and `pipeline.json`. The result binds the original preview, patch, exact character/profile inputs, request, pose artifact and implementation hashes. A changed source, preview, request or method cannot yield a complete inspection. Failure snapshots are retained when sampling has begun. Existing preview/bundle and character bytes remain unchanged. Saving a region still saves the original topology for explicit correspondence and contact preview/apply; this inspection never stages a patch or changes a target, cap, motion or scene selection.

The browser checks complete point/corner populations, selected animation/time, all source and preview bindings, geometry-derived triangle directions, areas, centres and aggregate degeneracy diagnostics before displaying the response.
