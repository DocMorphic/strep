# Accept corrections against saved motion

V6 exposed a precision failure: a step preserved every float64 solver row, but its float32/projected animation slightly worsened the frame 99 right palm normal. The measured angle increased from 15.061488267 to 15.061490400 degrees. That experiment remains diagnostic and unpromoted; its raw results are preserved. See [the preceding experiment](candidate-curvature-repair-v1.md).

The native contact-window runner now requires two separate acceptance checks before retaining a candidate. The existing solver population and the saved-motion population must each preserve passing rows, prevent regression of every protected failed row, avoid increased worst violation, and reduce squared violation. Both use their own last retained values. The original tangent, rig, control, trust, timing and resource limits remain in force. No tolerance is enlarged to accommodate rounding.

Saved geometry uses the actual float32/projected positions and rotations produced by reconstruction, all 18,056 native skin vertices and eight weights, the original reference motions, edited internal neighbors, and fixed exterior keys. The same conservative contact, normal, floor, object-clearance, displacement and speed formulas are evaluated through an explicit-pose entry point. Rotation rows intersect the original parameter budget with the measured saved local-rotation edit. Additional rows check actual saved root lift against its original bounds and fixed-joint edits against the existing limit. These are measured original rig constraints, not new permitted motion.

Every observed candidate records the complete saved row population alongside the solver rows and physical audit. The report binds the enabled policy, labels, initial/final populations and tradeoff mask. A separate hashed diagnostics file distinguishes solver preservation from preservation after serialization. Time or call-budget expiry returns the last candidate that passed every enabled acceptance check; a rejected repaired proposal cannot be promoted.

Resume recomputes saved rows from the archived motion files. New archives must reproduce both acceptance decisions, terminal flags and their diagnostics. Terminal arrays must match the final retained observation exactly, even when a difference falls within the reconstruction comparison tolerance. Legacy archives retain their original solver decision history, but each formerly accepted saved step must also preserve the physical population before it is eligible for continued optimization. A forged receipt or a changed policy cannot substitute for this replay. If all solver rows pass but saved rows fail, the stop reason explicitly identifies the saved-representation failure.
