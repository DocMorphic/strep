# Interaction alternatives after the constrained baseline

Research checked 2026-10-10 while the final fixed contact windows run. This record supplements the [scene-model decision](scene-model-next-steps-v1.md); it acquires no alternate weights, datasets, simulator or body model, and makes no release approval.

The immediate experiment remains the unchanged Kimodo checkpoint on the separate force-compatible target scene. Inspection of the pinned Strep adapter confirms that its end-effector guides carry hand/foot positions **and local rotations**, with source-FK consistency checks and an explicit shared coordinate origin. SOMA77 guides are reduced to SOMA30. Fingers and mesh contact are explicitly outside those controls. Compare unconstrained and guided generation, deterministic correction and the original failed targets using the complete existing surface/geometry/force audits. A plausible-looking grip or positive text score is insufficient.

| Alternative | Primary evidence | Consequence for Strep |
| --- | --- | --- |
| InterControl | Its [official implementation](https://github.com/zhenzhiwang/intercontrol) provides joint-guided generation, interaction examples and HumanML3D-trained checkpoints. The README identifies MIT code and separate terms for its dependencies/datasets. | Useful precedent for joint/contact guidance. Before acquisition, inspect the particular weights, body-model dependencies, coordinate representation and terms. Its code license does not establish rights to every required payload. |
| InterMimic | The [official implementation](https://github.com/Sirui-Xu/InterMimic) provides teacher/student training and inference. Its teacher demo releases one of seventeen OMOMO teacher policies; its setup uses separate Isaac Gym or Isaac Lab environments and external interaction data. | Candidate for an **offline** dynamics teacher that eventually exports baked clips. Do not replace the current runtime or assume its policies directly support a supplied game rig. Verify simulator, checkpoint, data/body-model terms and hardware cost before a bounded trial. |
| Uni-Inter | The [paper](https://arxiv.org/html/2511.13032v1) describes one interaction-conditioned framework. The inspected article version does not itself establish a downloadable checkpoint or product-training permissions. | Retain as research precedent; verify an actual implementation, weight release and terms before proposing an execution workflow. |

This is a choice about an authoring pipeline, not a gameplay controller. A physics policy would be an optional development tool whose output is baked to editable animation. No replacement is selected merely because a repository contains interaction videos. First complete and independently audit the fixed sweep, run the force-compatible scene/control comparison, and quantify remaining failures. A learned editor still requires demonstrated need, admitted data and measured learning curves; [genuine review and cleanup time](project-goal.md) remain absent.
