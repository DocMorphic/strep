# Stored-key native proposal differences

`scripts/stored_native_coupled_contacts.py` supplies the experimental `StoredNativeCoupledContactModel`. Its native finite-difference probes evaluate the existing Float32-key motion proxy, retaining the supplied decoded anchor. Its contact differences use the unchanged complete continuous contact model. All original native key, joint-displacement, linear/angular rate, contact-position and contact-speed rows remain present; the original surface contact rows remain in the objective and are duplicated into individual no-regression guards. Source caps, tolerances, uniform clocks, edit permissions and authored limits are unchanged.

This follows the [rate-stage trace](native-rate-stage-trace-v1.md): one saved forearm acceleration row passes at the stored baseline but fails at later exported keys, while the old continuously reanchored model predicts a pass. Native stored-key probes observe rounding variation at their finite stencil offsets. They do not establish a true derivative of discontinuous Float32 storage or a uniform error envelope. The contact stencil still uses continuous keys. Consequently this model does not guarantee that a new direction will improve the saved motion or pass export; the strict complete-affine gate, independently decoded native/contact conditions and full declared geometry audit remain necessary.

The default difference step is `0.001` normalized control fraction. Central probes use the full requested symmetric stencil where both endpoints fit the original control box. At a boundary, the existing helper records a one-sided probe using its matching stored origin, while retaining the separately supplied decoded anchor. It neither samples outside the authored boxes nor silently shrinks a symmetric stencil. The declared native nonzero budget defaults to `60000000`; exceeding it rejects the model rather than returning partial rows or columns. Only exact sparse zeros are omitted. Invalid step/trust/budget settings reject before native probes, and a decoded start with any failed native row cannot enter this improvement model.
