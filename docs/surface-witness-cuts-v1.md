# Refresh violating contact constraints without changing the motion objective

The converged scaled solve still violated fresh geometry because some closest-surface projections had changed. This experiment retains the original initializer, all 5,272 core surface rows, motion objective, relative slack penalty, hard joint/root/edit limits, five-degree local control neighborhood, and final selection screen. It adds newly measured violating surface rows as inequalities only. It does not add duplicate collision residuals to the objective or enlarge a frame's penetration allowance.

The frozen request is `reports/surface-witness-cuts-v1/request.json`. It permits at most three witness rounds with 60 SLSQP iterations each, complete-objective scaling by1,000 and `ftol=1e-12`. The initial rejected proposal is the completed scaled diagnostic. For every failing fitting time, all source vertices above that time's unchanged guard cap are retained. Each refreshed row is evaluated at the original initializer; an infeasible row stops the experiment with its evidence retained. There is no silent omission or cap increase.

The first round adds four rows, one each at frames66,66.5,67 and74. All four permit the original seed. The refreshed frame66/74 data are reused from their hash-bound prior verification; the other two frames receive fresh queries. The first inner solve converges in51 iterations, with a relaxed-constraint minimum near -1.08e-12. Fresh geometry rejects it: peak penetration improves from24.740384 to24.271273 mm, but frames74 and74.5 worsen by0.117035 and0.281964 mm. All other guard components pass. A lower objective or successful inner solve is not acceptance.

The second refresh retains all three newly violating rows. One static projection at frame74.5 (source1, target0, vertex6871) predicts21.591152 mm at the original initializer, above the fixed21.006530 mm frame cap. This stops the experiment before a second solve, with reason `refreshed_witness_infeasible_at_original_seed`. The candidate-derived plane incorrectly excludes the known original pose; its actual distance needs recomputation on moving geometry. The rejected candidate and every witness remain saved. See [the dynamic witness experiment](dynamic-contact-witness-v1.md).

Eight focused tests pass for complete row selection, immutable geometry/identity, explicit seed infeasibility, passing/failing threshold behavior, malformed inputs and the augmented inequality/budget layout. `FrozenContactProblem` also reproduces the original objective values at the initializer and prior rejected candidate before any new solve. Code is in `contact_restoration_problem.py`, `surface_witness_cuts.py` and `study_surface_witness_cuts.py`.

`finish_surface_witness_cuts.py` completed with `exported:false`; no step passed, so no export or engine audit was performed for this trial. The validation wrapper is `reports/surface-witness-cuts-validation-v1`. Its accepted-step path would decode limits, import both original/candidate pairs into Godot (600 actor-frames), and measure each pair at all299 whole/half-frame times. This still would not validate continuous-time collision, floor repair, anatomy, action correctness or animator quality. Root and legs remain unchanged, and every release gate remains open.
