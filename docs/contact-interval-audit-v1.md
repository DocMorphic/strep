# Measure the complete authored contact interval

The previous experiment verifies three native keys, 97–99, inside a two-hand grasp authored across frames 60–121. Those three keys do not establish quality or preservation across the complete action. The interval auditor now measures every requested saved contact key and the fixed body-reference edges just outside it, then ranks bounded repair windows by measured failures.

All original references, timing, rig budgets, grip targets, normal limits, floor limits and intentional-object-clearance policy remain bound. Each complete native skin evaluation uses all 18,056 vertices and eight weights. Current saved positions are supplied on both sides of each temporal edge, including edges that cross measurement windows. Explicit exterior-context updates invalidate derivative/representation caches without changing the reference motions. Coverage handles short tails and overlapping pairs without omitting or double-counting labeled rows.

Physical audits evaluate the saved arrays directly. The legacy pose solver retains its recorded parameter-root audit for compatibility; the new explicit saved-pose audit measures actual root displacement. A bound predecessor can supply a diagnostic pose overlay only after its original history is replayed. The whole-interval comparison separately records any passing row lost or protected failed row regressed against the original source; a narrow continuation result cannot imply global preservation.

The source clip and retained diagnostic windows contain different extra tracks, and the predecessor stores root positions at higher precision. The auditor explicitly compares four shared pose tracks, lists omitted source/predecessor metadata, and retains float64 root precision when merging the pose overlay. Original unedited values remain exact. Shape/precision preflight happens before expensive history replay, and data is used only after bound replay succeeds. The auditor does not copy stale contact flags into a proposed animation or invent missing event tracks. Metadata, engine import, action semantics, cleanup time and human quality remain unapproved.
