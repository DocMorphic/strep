# Reserved neutral partner import audit

`scripts/reserved_partner_engine.py` adds a headless Godot import check for all three reserved directed pairings. Each actor retains its bound character, profile and canonical placement from the verified portable neutral bundle. The input set contains six placed actors, 52,342 source vertex observations and 114 mapped joint origins. This is representation preparation for future partner evaluation; no reserved motion prompt, generated animation or correction outcome selects these layouts.

The engine script disables mesh compression and records every imported bone name, parent, world pose, skin bind, influence, triangle and mesh-space transform. `ImportedSceneSkin` checks the complete weighted bind functions against the version-pinned Godot 4.7.2 encoding, allowing equivalent duplicate functions and a consistent global triangle-winding reversal. It preserves triangle multiplicity and every source function. Matching only posed vertices would be insufficient: different inverse-bind/influence pairs can reproduce the same neutral pose while deforming differently later.

The reduction checks all bone positions, basis components and mapped role origins under their original actor placements. It reconstructs every neutral vertex from raw imported weights and world bones, without renormalizing the observed weights. Mesh and skeleton spaces must agree before that reconstruction; a displaced mesh cannot silently lose its transform. The fixed limits, chosen before actual engine execution, are `1e-5 m` for joint-position norm error, `1e-5` for basis-component error, `1e-4 m` for full-skin position norm error and `1e-7` for mesh-space/placement matrix components. Bind-function correspondence uses the existing `2e-6` component limit. These are representation checks, not motion or contact-quality tolerances.

The output retains raw engine records, complete expected/imported vertex and bone arrays, all role positions, source/runtime bindings and archived methods. Its saved-data verifier reloads the original neutral bundle and recomputes the complete skin/hierarchy/placement reduction, comparing every array and summary. This saved replay shares the rig decoder and skin-function checker with the producer; it is not a second independent engine or skin implementation.

An isolated public-source copy passed **65 tests** in **67.01 seconds**. Synthetic records cover all six actors, reversed bone/vertex order, full triangle correspondence, a changed skin function with the same neutral pose, dropped actors/bones/surfaces, changed unused-bone poses, invalid parent types/hierarchy, mesh-space mismatch, altered weights/binds, scope/version changes, rebinding saved evidence and exclusive worker/output handling. Engine subprocesses in these tests are mocked. The separate [completed actual Godot study](reserved-partner-engine-results-v1.md) now establishes the measured static import result for these partner fixtures.

The real import job completed after the exact existing warm-motion replay processes exited successfully. It required the completed seven closed populations, 6,216 reconstructed keys and a fresh complete 2,552-time geometry replay. The queue owned the predecessor process handles, held no production lock while waiting and did not start an engine in parallel with that study. Actual import and the complete saved-data reduction both pass for all six neutral actors. Methods imported by the subsequent stored-key refinement remain frozen.
