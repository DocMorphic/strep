# Original-bound skin export in Studio and game packages

The scene authoring panel offers **Condition skin weights for Godot export**. It is an explicit option, disabled by default. It preserves the original GLBs, creates separate weight-only derivatives, and measures imported skin against the originals. Contact, geometry and optional current speed limits still apply; a fidelity failure keeps the sampled scene decision failed.

Saved Studio v1/v2 drafts preserve the option as `"skin_weight_export": "godot-u16-original-fidelity-v1"`. Contact revisions treat it as protected original intent. The backend writes a strict authoring v3 recipe with an explicit nullable speed-policy binding. Ordinary v1/v2 recipes remain supported.

The ordinary authoring pipeline now runs per-actor skin exports after an optional object edit, then imports the exact derivative clips and records original-reference fidelity. Original references stay bound to the initial inputs even when object fitting makes byte-identical working copies. Animation selection and placement must remain unchanged. The existing 0.1-mm skin tolerance, source motion, clocks and geometry limits are preserved.

Scene downloads distinguish originals from conditioned GLBs. The portable scene ZIP uses derivative clips at `actors/<index>.glb`, retains originals at `originals/actors/<index>.glb`, and includes `skin-weight-export.json` with original/derivative hashes and per-actor fidelity results. That receipt contains portable identities rather than local input paths. Existing correction, transition, contact and export-speed records remain available.

Game packaging loads the active geometry policy and exact measured derivative identities. It copies the scene ZIP members unchanged, including originals and the weight receipt, and adds root references, declared contacts, gameplay markers and the finite event helper. Its result and package manifest explicitly carry the export mode and original-reference decision. Root motion remains embedded in the clips; extracted tracks are references and must not be applied a second time.
