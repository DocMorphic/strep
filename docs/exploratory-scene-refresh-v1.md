# Refreshing scene models without resetting acceptance

Development experiment, 2026-10-18. This study retains a partial numerical
correction after complete original-frame checks. **It does not approve an
animation.** Forty-one physical rows still fail, and no changed animation is
exported, selected in Studio or substituted for the qualified reference.

The two-character high-five remains a development case for general scene
correction. Action families are not a prompt whitelist; the broad project
goal and all original release requirements remain active.

## Original source, new numerical center

The previous local model underestimated movement at a point already included
in its collision bundle. Increasing margins in that same first-order model
made it infeasible. This experiment refreshes the complete model around the
rejected exploratory pose while retaining the original native clips, author
limits and final gate.

Six serial jobs cover all **120 original integer frames**. Each frame has
both actor floor rows and both directed partner rows: **480 geometry rows and
72 control columns**. All original 18,056 vertices, eight skin influences and
36,108 target triangles remain. Sampled articulated evaluation reduces local
rotation work only. The first 55 frames reproduce the earlier saved auditor
values exactly, with identical strict pass masks. No independent directional
check of every one of the 480 macro derivatives is claimed.

The global model refreshes three points, three normals, two tangents and eight
complete skin/joint speed/acceleration tracks. Its sixteen scalar rows and
33 vector components pass the predeclared 0.1% directional check. Dense and
streamed reference values, strict masks and peak identities agree exactly.
Perturbations tangent to nearly active original control balls keep both sides
of the derivative check inside the original author domain. These are technical
checks; physical thresholds are unchanged.

Original five-degree joint and two-centimetre root limits remain relative to
the original native tracks. Protected and unselected keys retain their
original permissions. The new numerical center does not create a fresh edit
allowance.

## Actual nonlinear result

| Fraction from exploratory center | Actual checks | Decision |
| --- | --- | --- |
| Full | All sixteen global rows | Reject: A meeting point and hand-to-hand point fail fixed checks |
| Half | All sixteen globals and every frame 0..119 | Retain as a partial numerical correction |

The half step passes every original required and protected condition, remains
inside every original author control ball and strictly reduces the original
maximum normalized working violation from **5.509566 to 5.442634**. The quarter
step is not tested because the half step passes the fixed retention gate.
On any rejection, the pipeline returns the original guard state, never the
unapproved exploratory center.

Retention here means a complete numerical step satisfying that fixed subset
and progress rule. **Forty-one of the 496 physical rows still fail.** In
particular, a retention pass is not a claim that all global orientations or
all partner overlaps pass. The retained controls remain a diagnostic artifact;
the Studio selection and qualified reference are unchanged.
