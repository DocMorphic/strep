# Movement-profile response after rig transfer

This study reuses every clip from `profile-response-v1`: three actions (wave, squat, right-leg kick), four conditions (plain, mobility low/middle/high) and three matched seeds. It exports all 36 source clips to all three existing character fixtures, covering two rig families and different proportions. No new inference, conditioning, correction or profile wording is introduced. This is development evidence, not held-out evaluation.

The source profile already fails its numerical direction screen for squat and kick. Retargeting is therefore evaluated as a separate stage: does the same measured response survive on the supplied character, change order or become less distinct? A successful export cannot establish that the source performed the right action or followed its style description.

The frozen protocol is `reports/profile-transfer-v1/protocol.json`. It uses the original whole-clip p95-minus-p5 angle excursions, the original five-degree high-minus-low margin, the same low/middle/high median ordering and the same two-of-three-seeds rule. Target measurements use explicit mapped semantic joints from decoded GLBs. Root orientation, uniform scale and bone-index order do not change the descriptors, but different proportions and anatomical landmark placement can. Missing landmarks are rejected instead of replaced with a different definition.

All 108 transfers and 144 native/target clips receive the existing export, root/contact-sidecar and actual Godot import checks. Target floor penetration and predicted-support diagnostics remain alongside the angle measurements. The complete report retains failed or missing rows, with incomplete groups unscored, and keeps independent action/style review empty.

`profile_transfer_study.py` freezes the fixtures and source hashes, runs the existing transfer pipeline, then computes the matched descriptors from every exported frame. All 108 transfers, 36 engine groups and 17,280 actor-frame checks completed. Results are under `reports/profile-transfer-v1`; the complete comparison is `reports/profile-transfer-summary-v2/comparison.md`. The earlier summary is retained; v2 adds hover diagnostics without changing the response analysis.

All nine target/action screen outcomes match the native outcome: waving passes, squatting and kicking fail on each rig. Individual primary excursions change by up to 12.8896 degrees. This preserves the pass/fail result of a narrow numerical response screen, not semantic style adherence or action quality.

All 36 rig01 clips exceed the 10 mm floor screen. Rig02/03 show zero penetration but predicted-support foot-envelope hovering of 82.57–108.52 mm and 80.53–102.64 mm respectively. These hover values depend on predicted support labels; they are not independently authored contact measurements. Rig02 also lacks a sufficiently flat automatic sole draft. Export integrity passes while grounding quality remains unresolved. No new generation, correction, independent ratings or cleanup-time evidence was produced.

Eight metric checks pass, covering semantic remapping, rigid-transform/scale invariance and invalid/missing mappings or geometry. Initial preparation rejected the current whole-file analyzer hash: inspection found only a model-directory portability change since the original study. The retained executed file matches the original analysis hash, and all four metric/scoring function ASTs match exactly. Preparation binds both versions and copies the executed source; definitions and source motions remain unchanged. See `reports/profile-transfer-preflight-v1.json`.
