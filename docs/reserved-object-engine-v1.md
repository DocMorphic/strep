# Static object engine-import audit

`scripts/reserved_object_engine.py` connects the constructed object reservations to a headless Godot import check. It rechecks the complete construction catalog, request, implementation snapshots, asset/descriptor/verification hashes and saved geometry before creating a fresh engine project. It imports every supplied object and retains raw engine observations and complete provenance. It never generates motion or changes an object reservation.

```powershell
python scripts/reserved_object_engine.py PATH_TO_CONSTRUCTION PATH_TO_FRESH_ENGINE_OUTPUT --engine PATH_TO_GODOT_CONSOLE_EXECUTABLE
```

The existing action-worker lock prevents concurrent production work. A real attempt while the restored-scene worker was busy was refused before any output directory or engine process was created. The current five-object production audit is queued behind the exact Windows process handle of the independent restoration replay supervisor, with launch identity and source/input hashes retained. It requires successful terminal evidence for that serial chain before starting. **The new object engine script has not yet executed or been parsed by Godot.**

The GDScript uses [GLTFDocument's compression-disable flag](https://docs.godotengine.org/en/stable/classes/class_gltfdocument.html), inspects the [ArrayMesh primitive type](https://docs.godotengine.org/en/stable/classes/class_arraymesh.html) and writes [full-precision JSON](https://docs.godotengine.org/en/stable/classes/class_json.html). These APIs were checked against official documentation; that check is not runtime proof. The script rejects animation/skeleton data, missing meshes, extra surfaces and nontriangle primitives. It records complete positions, normals and indices, then observes local-origin and canonical grounded placements.

The Python reducer expands imported indices and compares the complete triangle-position multiset to the saved Float32 GLB values **exactly**, allowing importer vertex/index reordering. Normals retain their point correspondence and must differ by no more than 1e-4 per component. Winding must be consistent across the object; either global sign is recorded explicitly because Godot's convention can reverse glTF winding. Both observed translations must be within 1e-6 m of their declared placements, with identity bases within 1e-6 per element. These fixed representation checks are separate from animation realism and the release gates. Bounds are not enlarged after an import failure.

Every expected triangle and both placements are required. Missing/duplicate objects, missing triangles, a one-ULP changed position, altered normals, mixed winding, invalid/boolean indices, nonfinite data and changed placements are rejected. Inputs and methods are rehashed before success; failed raw outputs and engine logs remain available. The original construction is preserved. No rendering, runtime physics, reachable grip, human quality or release approval follows from static import success.

Fifty Python checks pass in the working tree and a fresh source-only copy. Engine observations in these fixtures are explicitly synthetic, with no Godot execution. One initial changed-placement test aliased its synthetic observation to its expected request; mutating it changed both. The failing fixture was preserved, repaired with a deep copy, and rerun. Production request and engine records are read from separate JSON files. This was a test-fixture defect, not a measured engine failure. The 50 checks include the static constructor and triangulation suites plus complete-population reductions and changed source receipts. Windows/Ubuntu source CI includes the new suite.
