variant and the original stays selected. This is one development clip, not
held-out action coverage or an animator-quality result.

The explicit boundary contract preserves both endpoints and reproduces the
original intended keys. Source-cap arrays and 120-Hz rate clock remain exact;
the 1e-5 rate tolerance, 30-degree track bounds, 0.22-m displacement bound and
frozen root are unchanged. Each component choice is absolute relative to the
nearest Float32 value of the fixed intended curve. It may be restored or
replaced, but cannot accumulate more than one neighboring value. The existing
policy permits up to 64 corrected components; the search does not change that
envelope or introduce a new editable key.

Every exported candidate receives strict track/frozen-key/static-payload checks,
fresh native decoding and the complete declared floor population: 2,017 times,
1,029 referenced vertices and 1,604 faces, with the original 5-mm allowance.
