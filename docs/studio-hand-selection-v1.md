# Select the character's hand-contact surface

Studio's scene contact editor now supports selecting individual hand triangles in the preview. It complements [object grip picking](studio-grip-picking-v1.md): the developer can choose both the hand region and the point on the target object. This extends the existing canonical SOMA scene workflow, not arbitrary imported character topology.

In **Scene interactions → Fit hand contacts**, select an actor/contact and choose **Frame selected hand**. **Select hand triangles** adds triangles with clicks; **Remove triangles** or Shift-click removes them. Escape ends selection and restores the prior camera-control state. Cyan marks the selection and amber marks available triangles while selecting. Orbit before entering selection mode. Clearing a patch is allowed while editing, but an empty patch cannot be submitted.

The selection becomes **Selected hand triangles** in the region menu and persists with the scene revision. Switching back to a saved or suggested region removes custom fields from the submitted request. Source motion remains unchanged. **Fit included contacts** snapshots the authored request, runs the existing regional fitter and independently audits the exported candidate; a completed fit is not quality approval.

## Binding and preservation

The backend supplies eligible nondegenerate triangles whose nonzero influences all belong to the declared hand and fingers. Before picking, the client checks vertex/face counts, indexed topology, bind positions, joint names, all eight skin influences and inverse bind matrices against the loaded preview. It requires a unique matching mesh on the selected actor. The highlight and ray intersections use all eight weights, including actor placement; the default four-weight CPU raycast would not match this character's displayed skin.

The explicit request carries the canonical mesh fingerprint and selected triangle IDs. Server validation rejects stale identity, duplicates, nonintegers, wrong-hand/body faces and out-of-range indices. Existing region limits remain: at most 256 distinct vertices; the new selection additionally limits a request to 512 triangles. The guide anchor is retained when possible, otherwise rebound to the nearest bind-space vertex inside the new patch. Contact limits, source-relative motion budgets and independent export checks are unchanged. Disconnected regions are possible; selection alone does not establish anatomical suitability, a contact witness or reachability.

The overlay follows playback without changing mesh geometry or source animations. Selection pauses playback and restores the previous camera-control state when cancelled. Hidden/changed scenes, actor/contact changes and source resets cancel picking. Suggested radius/angle edits invalidate the initial patch preview instead of displaying stale geometry as the newly calculated region. The developer may return to the original suggestion, clear and author a custom patch, or fit the revised suggestion.
