# Continued clearance and a different ground action

These development experiments extend the
[original-bound Studio clearance trial](studio-native-storage-v1.md). They test
continued correction under the same source epoch and the existing crawl
boundary-authoring contract. They do not establish general action coverage or
approve either animation.

The kick continuation loads the preceding Studio job's exact corrected native
state, including six explicit stored-component corrections. Its 72 controls,
source asset, contact scene, geometry policy, cap arrays, rate clock and 8/16
export-repair effort stay unchanged. It requests one more clearance iteration.
Changed candidates remain separate from the original; full native and floor
audits still decide their recorded outcome. Geometry failure prevents staging.

The crawl uses the existing development asset and earlier 63-control budget:
root translation plus the two arm/forearm/hand chains, 22-cm root/joint movement,
30-degree rotations, three control times and explicitly editable actual clip
start/end keys. These permissions already existed in the
[earlier crawl trials](kenney-crawl-plane-envelope-v2.md). The new trial wraps
that same boundary intent in the explicit stored-export repair contract. It
uses one decoded surface iteration and 4 repair stages / 8 probes per stage.
The original source-rate caps and 5-mm floor limit are unchanged.

Both trials retain the complete declared clock and all actor geometry. Crawl
uses all 2,017 original/native/frame times and all 1,029 triangle-referenced
vertices. No invented contact targets, subset of the worst frames, new model
generation or held-out reservation is introduced. Boundary edits do not inherit
start/end transition compatibility. Existing rotation-component export repair
does not grant permission to alter root translation keys beyond their authored
track bounds.

Each worker records source/method hashes and preserves original assets and
failed probes. Separate guards use the unchanged admission, memory and
900-second execution policy. Resource replay checks recorded supervisor policy
and bindings independently; it does not validate animation. Final numerical
replay, when available, is reported separately from producer measurements and
hash validation of failed search archives.

The earlier ground scenes show why boundary intent matters: crawl already
penetrates the floor at both clip edges. An interior-only correction cannot
clear those unchanged poses. Get-up additionally fails a generous 22-cm start
reach screen; allowing endpoints alone does not establish feasibility. See
[complete-clock ground measurements](kenney-ground-scenes-v2.md). Different
source/target anatomy and the existing retarget profile remain relevant;
these experiments do not prove the cause of the original defects.

## Independent final and rejected-candidate replay

A separate worker freshly reconstructs the completed kick export byte-for-byte,
every native residual/world, original cap array and rate clock, and zero root
translation error. It independently recomputes every floor sample with identical
results. All fourteen native search archives receive hash validation, rather
than complete numerical replay of their failed neighbors.

It also freshly reconstructs rejected crawl probe `1-2`, all 107,895 native and
intended conditions/worlds, original cap arrays/clock and every floor sample.
The intended motion has zero failures; its returned export has 52 failures
(35 positional acceleration, 17 angular acceleration), and still penetrates
257.398701 mm at its worst point. Its best partial greedy rotation repair has
46 failures and was never selected as a passing repair.

Root node 21 has a stored positional-acceleration failure at row-frame index
215 while its intended root acceleration passes. The permitted rotation nodes
are 29, 30, 31, 40, 41 and 42; none lies in the root's ancestor set
0, 1, 20, 21. With this continuous candidate and the other tracks held fixed,
those rotation-only storage changes cannot alter node 21's world translation.
The saved best partial repair has exactly the same root worlds as the returned
candidate, matching that structural limitation. This establishes an uncovered
component type for this candidate; it does not prove that another continuous
curve or a translation repair will solve the complete scene.

The separate worker shares the repository's decoders, cap arithmetic and
geometry routines; this is fresh computation from bound inputs, not an
independent mathematical implementation. It completes at **54.750 s execution**,
and all 72 resource observations replay. Evidence remains in
`reports/studio-kenney-clearance-continuation-v1`,
`reports/kenney-crawl-stored-boundaries-v1`,
`reports/kenney-crawl-stored-diagnostics-v1` and
`reports/stored-ground-final-replay-v1`. Both original motions and every failure
stay retained; no geometry, human, training, engine or release approval follows.
