# Root-aware correction on the two remaining held rigs

The preceding fixed-root method cannot repair an existing root-acceleration failure. This development protocol allows root translation and unprotected leg coordinates to move inside one selected temporal block, while retaining the original absolute and adjacent edit budgets, floor and hover bounds, local-rotation maximum, foot acceleration and support-speed envelopes, and no-new-release protection. It does not change the unchanged model checkpoint or declare the original motion physically correct.

The target is selected before fitting: the largest current root-acceleration excess over the existing raw/prior comparison cap, with a five-frame block centered on that sample. Root acceleration is constrained at every affected center, including neighboring fixed frames. Its initial per-center safety envelope is the larger of the original comparison cap and the original held magnitude; it remains frozen across follow-up blocks. The objective reduces the selected failure toward the original cap. Other failures stay in the population.

`scripts/root_release_block.py` extends the existing coupled surface problem. It adds serialized root positions, root-translation Jacobians and normalized acceleration inequalities. An edited ancestor of the root is rejected because it would invalidate the assumed translation derivative. All nonlinear acceptance values use the serialized pose; derivatives are smooth proposal approximations, not derivatives of the float quantizer. One SLSQP proposal receives at most80 iterations and eight fixed safeguard fractions. Rejected proposals and intermediate infeasible iterations are retained.

Three focused tests pass in3.17seconds: both-neighbor root derivatives and non-root zero columns; complete objective/constraint derivatives and cache behavior; and a synthetic root spike reduced while unrelated frames and leg coordinates remain fixed. Actual-mesh preflights on both65-bone rigs pass three directions each at1e-6. Maximum errors are7.54e-6 and9.89e-6, below the unchanged2e-4 diagnostic threshold. Both rigs protect the original peak local-rotation joint, node56.
