# Complete decoded checks after translation proposal ranking

The [translation-stencil proposal study](native-translation-stencil-v1.md)
demonstrates that coordinating several axes and keys can repair an export-only
failure. `scripts/native_translation_stencil_search.py` now provides an
explicit optional search using those proposals. Existing fitting/search
defaults stay unchanged.

## Search contract

The planner retains all original rate failures in its diagnostics. It targets
the worst supported positional acceleration row, then chooses the closest
explicitly permitted ancestor translation track. Its three uniform samples
must have complete editable support on one to three consecutive native keys.
Unsupported rows remain unresolved; this proposal family does not repair
angular motion or contacts by assumption.

All axes receive absolute negative-neighbor, nearest-value or positive-neighbor
choices. The complete local population is ranked before applying the separate
export budget. Equal predicted target errors prefer fewer absolute corrections:
a regression test catches how equally ranked extra offsets can create jitter
elsewhere, even when nearest-value restoration would repair the entire fixture.

Every actual proposal still goes through the existing checked search. It exports
fresh files, independently decodes complete actor worlds, recomputes every
original motion condition and compares the original caps/scales/population.
Authoring, control boxes, native support and the original one-neighbor correction
envelope remain required. Geometry is a separate gate. No passing local
prediction is treated as animation acceptance.

prevent the real root-jitter fixture from passing. The corrected ordering passes
all 179 related tests in 54.54 seconds, including sixteen new atomicity,
permission, real export, source preservation, forged-decode and unsupported-rate
checks. Its 72 resource observations independently replay. These overlap the
earlier 163-test population and are not summed as distinct checks.

## Next decision and limits

The local target ranking can trade an error for a smaller error elsewhere in
the same native support. The next proposal ranking should consider the complete
affected interval and joint population, then retain the same full decoded
acceptance checks. A finite exported prefix does not establish impossibility
of a feasible stored clip.

All authoring/source/63-control/cap/clock conditions remain fixed. These are
sampled motion/floor results on one development rig/action, not semantic,
continuous collision, engine, held-out or human-quality approval. There are no
new weights or training admission. All fourteen release capabilities remain
unapproved under the single whole-project goal.
