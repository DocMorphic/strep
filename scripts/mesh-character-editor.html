Correct character contacts with objects

Save and measure the object-contact scene above. In Character correction, choose Contact adjustment, load scene joints and save bounds for each character to edit. Then run the correction here using those same bounds.

Joint turning-speed limits, clearance mode and extending a previous correction are not supported here. An interrupted new correction can continue with its saved scene and bounds.

Detailed character and object checks can take longer on a CPU. This is a maximum, not an estimate. Longer time keeps the same memory guard, accuracy checks and edit bounds; it does not guarantee a usable correction.

Original clips remain selected. Every attempt is retained for review.
