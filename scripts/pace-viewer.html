What the pace control does

Uniform retiming changes speed and cadence together. It keeps the same poses and stride; it does not generate a new gait or independently set cadence. Preview speed changes only your viewing speed.

Foot sliding is estimated on the lowest persistent foot-mesh patches during predicted contact. Rolling feet and incorrect contact predictions can affect this estimate. These engineering checks are not independent stance annotation, animator approval, collision simulation or engine-import validation. Small inherited floor penetration remains visible.

The root track contains SOMA pelvis transforms in meters, Y up and +Z forward. A target engine's root-extraction convention still needs selection. The NPZ must be used with its timing JSON. All four seeds were observed previously; this is not a new held-out evaluation. Agility, strength and stamina mappings remain uncalibrated.
